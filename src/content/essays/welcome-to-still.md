# Welcome to Still

First of all: thank you.

There are thousands of Astro themes out there, many of them excellent. The fact that you landed here—and perhaps even decided to use Still—means a lot to me.

I didn't build this theme because the world desperately needed another blog template.

I built it because I wanted one that *I* would actually enjoy using.

## The web used to feel different

There was a time when having your own website felt... normal.

You'd buy a domain, upload some files, write a few thoughts, maybe share some photos, and call it a day.

No algorithms.

No feeds.

No engagement metrics.

Just a place that was yours.

Somewhere along the way we stopped building websites and started renting them.

Our blogs became Substacks.

Our portfolios became Behance profiles.

Our communities became Discord servers.

Our writing became social media posts.

Convenient? Absolutely.

Permanent? Not really.

Still is my small contribution toward reclaiming that little corner of the web.

## Why Astro?

I've spent enough years building websites to know that no framework is perfect.

Every tool comes with trade-offs.

Astro happened to strike a balance I really liked.

It embraces the web instead of trying to replace it.

Pages are HTML first.

JavaScript is optional.

Markdown feels like Markdown.

The end result is a website that's incredibly fast, easy to host, and—perhaps most importantly—easy to understand.

When I open this project six months from now, I don't want to spend an afternoon remembering how it works.

I want to start writing.

## Why "Still"?

Because I think the web needs more stillness.

We're surrounded by interfaces designed to compete for our attention.

Popups.

Notifications.

Infinite scrolling.

Auto-playing videos.

They're all trying to answer the same question:

*"How do we keep someone here for another thirty seconds?"*

Still asks a different one.

*"What if those thirty seconds were actually enjoyable?"*

It's a small distinction, but it changes how you design.

## What Still is

Still is a theme for people who enjoy making things.

Writers.

Photographers.

Designers.

Developers.

Researchers.

Teachers.

Anyone who believes ideas deserve a comfortable place to live.

It's intentionally minimal—not because minimalism is fashionable, but because your work should be the loudest thing on the page.

## What Still isn't

Still isn't a no-code website builder.

It isn't a CMS.

It isn't trying to be WordPress.

If you're looking for something where you can drag boxes around and publish without ever touching code, there are excellent tools built specifically for that.

Still assumes you're willing to learn a little.

Not because learning is a requirement, but because ownership is incredibly empowering.

Once you understand how your own website works, nobody can suddenly raise the price of a feature you depend on.

Nobody can decide your content belongs behind another subscription.

Nobody can take your website away from you.

That's a wonderful feeling.

## Don't worry if you're new

If you've never used Astro before...

Welcome.

If you've never edited a Markdown file...

Welcome.

If GitHub feels intimidating...

Welcome.

Seriously.

I wrote this documentation for you.

We'll go one step at a time, and by the end you'll have something that's completely yours.

Not mine.

Yours.

## Make it yours

One small request.

Please don't keep Still looking like Still.

Change the typography.

Replace the colors.

Move things around.

Delete components.

Add new ones.

Rewrite everything.

The best compliment this project can receive is becoming unrecognizable because you turned it into something uniquely yours.

## Let's build

The next article will guide you through downloading the theme and running it locally.

From there we'll cover writing, customization, deployment, and everything else you'll need to publish your own website.

By the time we're done, my hope isn't simply that you'll know how to use Still.

It's that you'll feel confident enough to build the next thing without it.

Because ultimately, that's the goal.

Not to create users.

To create makers.

See you in the next chapter.
